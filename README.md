## 🚀 Getting Started

Follow the steps below to run this project on your local machine.

### 1. Clone the repository

```bash
git clone https://github.com/Asadulpy/web-dev-portfolio.git
```

### 2. Navigate to the project directory

```bash
cd web-dev-portfolio
```

### 3. Run the project

This is a frontend project, so no package installation is required.

You can open the `index.html` file directly in your browser.

For a better development experience, you can also use the **Live Server** extension in VS Code.

## 💻 Local Development with VS Code

1. Open the project folder in VS Code.
2. Install the **Live Server** extension if you don't already have it.
3. Open `index.html`.
4. Right-click on the file.
5. Select **Open with Live Server**.

The website will then open in your browser.
